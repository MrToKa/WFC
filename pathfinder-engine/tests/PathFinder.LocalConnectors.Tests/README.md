# Bounded local approach checks

The console suite references the actual Core and Barriers libraries. Its independent
closed solid/tunnel fixtures are qualified by the triangle kernel before routing.
No source files are compiled a second time, and no historical expected fixtures,
model/cable/database rows, browser state or running installation are modified.

It checks offset wall/floor openings, both endpoint detours and length accounting,
actual final triangle clearance, retained waypoints, finite-domain limitations,
original strategy parity, explicit drilling, deterministic search and shared budgets.
The lattice is search guidance: finite-resolution exhaustion is not a physical
no-path proof. The scope remains centreline-only and registered-object-only.

The root executor can run from the isolated worktree, selecting an owned artifact
directory when required:

```powershell
dotnet run --project pathfinder-engine/tests/PathFinder.LocalConnectors.Tests/PathFinder.LocalConnectors.Tests.csproj --configuration Release
```

The emitted JSON and exit code describe the actual run. Runtime/peak measurements
apply only to this synthetic suite; they are not real-model or maximum-capacity
qualification, native parity or engineering approval.
