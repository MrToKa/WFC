# Ordinary application CAD drawing — activation and acceptance, 2026-11-15

CAD tray drawing now runs in the ordinary application and in its currently selected 3D model. It does not require a separate model, database name, database account or storage bucket. The optional explicit-off switch remains available; normal builds/startup default to CAD enabled.

## Use
Project → Routings builder → Draw trays → New tray. Choose a Materials component and its STEP revision, prepare it for the project, then position with a model point, coordinates or qualified connector snap. Manual routing and Cables remain sibling modes in the same viewer. Draw workspace/meshes survive mode changes; access/model changes retire the old workspace. Saved named routes and STEP/material exports remain available. Materials → Components manages real source revisions; administrative upload and project edit permissions are unchanged.

## Ordinary deployment
The API and converter use WFC_CAD_CONVERTER_TOKEN (at least32 printable nonspace characters); legacy POC_CONVERTER_TOKEN remains compatible. WFC_CAD_CONVERTER_URL remains the private http://cad-converter:8090/convert. The converter is a separate constrained process, not a separate model/application: nonroot/read-only, dropped capabilities, limited CPU/memory/processes, writable bounded temporary storage, no host port. STEP body/mesh/output/time/assembly limits and hash-qualified geometry/ports remain enforced.

Dockerfile defaults VITE_CAD_DESIGN_ENABLED=true. Both ordinary compose variants include the converter and ordinary API configuration. scripts/update-local-app.ps1 reuses current DB/JWT/storage settings, retains/generates the private token and starts converter → backend → frontend with separate health waits. It snapshots all three old images/environments and converter absence/running/stopped state for rollback. Optional VerifiedConverterImage alongside VerifiedApiImage/VerifiedWebImage avoids rebuilding any of the three. Compose2.24.4+ is required for exact rollback environment replacement; unsupported versions refuse before changing services. Private tokens are never committed.
