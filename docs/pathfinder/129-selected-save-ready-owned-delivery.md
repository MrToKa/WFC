## Delivered behavior

Save confirms the shared From/To assignments and calculates the open cable
first. Its own result and automatic-write disposition determine popup readiness;
the remaining cables continue in the background. Assign, Calculate and Show
recover automatically when this cable is ready. Show uses the already verified
display payload. Changed inputs, revisions, failures or cancellation invalidate
that payload.

Cables with the same ordered From/To and identical calculation inputs reuse the
source cable's checked native result. Their endpoint references, route and length
are updated without repeating native search or loading and qualifying shared
geometry. Each recipient retains its own database record, revision, proposal,
seal and Auto calculated length. Unchanged Routing/Design values previously
written automatically can update automatically; manually edited pairs retain
Review and Apply. Different endpoint pairs or calculation conditions follow
their own calculation.

See [the implementation and verification note](128-selected-save-completion-and-shared-computation.md)
for bounded read recovery, source priority, exact reuse equivalence and cache
limits. Loading this installed version requires closing an old popup and
reloading its main page once; normal completed calculations then update their
own readiness without a manual cable Refresh.
