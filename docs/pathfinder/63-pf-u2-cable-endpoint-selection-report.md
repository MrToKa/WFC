cable. Exact SDK selection uses a startup-created index and checks the current
model, preparation, trace, frame, record hash and supported bottom-centre anchor.

point/object proof. An explicitly labelled fixed point remains available without
claiming retained object attachment. Empty logical names require setting the
name in Cable list first. MV is excluded from authoring in this workflow.

One authorized transaction creates or updates the shared project location,
preserves aliases, records its immutable binding and exact command receipt, and
counts matching cable endpoints on both ends with cable deduplication. A receipt
does not change cable routing, design length or installed length. Exact replay
returns the original committed result even after context changes. Explicit close
records a permanent tombstone; a late original request cannot subsequently save.
Current account, administrator role, login and expiry remain checked through the
transaction. A lost acknowledgement remains unknown and is reconciled by key.

The new frontend foundation retains one uncertain command per account/project
in bounded browser storage, serialized through Web Locks and read back before
sending. Generic errors never erase it. Only an exact owner/key/hash receipt or
immutable closure can clear it. Pause preserves drafts/recovery; model/account
changes hide old selection. A confirmed save retires stale context before refresh,
including a pause immediately after storage clearing. No Viewer Tab/popup is
mounted yet; that integration belongs to U5.
