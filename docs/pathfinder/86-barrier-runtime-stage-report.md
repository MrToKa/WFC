## Implemented

- New strict dependency v8 / preview v6, runner request v2 / response v3. The exact
  model/frame, published barrier revision/snapshot, explicit drilling choice,
  fixed bounded profile and server-owned immutable file references travel together.
  No client path, inline mesh, unknown field or missing policy becomes legacy work.
- Fresh manual/standalone/scoped calculation requires an explicit current intent.
  Endpoint Save verifies that intent and retained publication before any binding
  write or pending impact. Exact old receipt recovery and endpoint-only Save remain
  supported. Browser-open and browser-closed producers derive the current published
  scope themselves with drilling off, including when old preferences lack a scope.
- C# validates actual retained manifest/capture bytes, source/frame memberships and
  closed-triangle qualification; uses the constrained/local strategy and one shared
  absolute budget; records the final ordered route checks separately from search
  diagnostics. Direct SECONDARY falls back to trays when obstructed, retaining the
  actual strategy's original C# length ledger. MV is excluded before fresh dispatch.
- One qualified scope/kernel is cached in the session. Exact bytes are reread and
  hashed between items to detect changed storage; this is not an I/O-free cache or
  a measured 2140-cable performance claim. File/ancestor identity, regular-file,
  no-link, size and digest checks run on Windows and Linux. Combined child memory
  is sampled at 100 ms against 512 MiB; this is not an instantaneous ceiling proof.
- Ordered IEEE754 little-endian route hashing avoids cross-language exponent
  formatting. Only signed zero is normalized for JSON/JSONB durability. Nonzero
  coordinate bits, ordering/count and the pinned C# geometry/math are unchanged.
  Endpoint validation retains the core's exact zero-distance underflow behavior.
- New implementation identity v2 includes the six actual assemblies and an
  explicitly bounded projection closure (41 files, limit 64). The original identity
  body/reader remains a separate version; no fictitious Geometry/Support DLL exists.
- Published barrier changes emit one transactional scheduler event. Old currentness
  fails safely: expected scope/capture loss makes retained history stale/readable;
  a publication during dispatch retains the exact completed result as stale and
  completes that item, while siblings continue. Authority, cancellation, implementation
  and unexpected I/O errors are not hidden as normal scope changes.
- Sealed v8/v2 applicability supports independently completed scoped cable items.
  Result UI distinguishes registered-scope clear, drilling bypass, explicit empty,
  blocked, indeterminate, bounded incomplete search, unavailable and unchecked history.
  Search blocking is never presented as an invented final surface hit. Background
  options remain drilling-disabled independently of the current manual checkbox.
