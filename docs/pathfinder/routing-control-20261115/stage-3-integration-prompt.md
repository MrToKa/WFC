## Native contract to use exactly

Protected calculation request:

```json
{
  "schemaVersion":"pathfinder.model.runner.v2",
  "operation":"calculate",
  "manualRouteConstraint":{
    "schemaVersion":"pathfinder.manual-ordered-route.v1",
    "routeText":"/A/B/C"
  },
  "includeLengthLedger":true
}
```

Include all ordinary admitted project/model/snapshot identities/hashes, actual From/To world-metre points, category, numeric routing options, exact Project Details settings, purpose permissions, capacity exclusions and current authenticated barrier context. No reverse and no lookup/design-only request. Freeze raw manual text and manual_revision in a versioned manual dependency object; do not insert manual text into global automatic numeric options or rewrite stored text from normalized native route output. Direct SECONDARY shortcut is intentionally suppressed. Terminal SECONDARY uses checked endpoint approach semantics and measured reserve flags; interior/only SECONDARY or adjacent repeated tokens are explicit unsupported diagnostics; `/A/B/A` is supported. Bounds: 16,384 text characters, 100 physical codes.

Response stays the existing protected response.v3 (`route`, `design`, `lengthLedger`, barrier execution/qualification/exact final proof). `design.designLengthMeters` is the full cable design length from ordinary native formula, not a lookup tray total; ordinary `wfc.pf.length-components.v1` ledger contains actual approaches/reserve replacement/allowance/bending/ceiling. Both legacy registered closed-solid and current mixed original-surface policies are exercised. Authenticated mixed v3+ maneuver flag and v5+ nearest-anchored behavior are respected.
